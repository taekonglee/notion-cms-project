다음 절차에 따라 `docs/ROADMAP.md`의 완료 상태를 현재 코드베이스 기준으로 업데이트하세요.

## 1단계: 완료 작업 파악

아래 두 가지 소스를 모두 확인하세요:

1. **shrimp-task-manager**에서 완료된 작업 목록 조회:
   - `mcp__shrimp-task-manager__list_tasks` 도구를 `status: "completed"`로 호출
   - 각 task의 이름과 ID를 기록

2. **코드베이스 직접 확인**:
   - ROADMAP.md의 각 Task 항목에 대응하는 파일/기능이 실제로 존재하는지 Glob/Read로 검증
   - 파일이 존재하고 구현이 완료된 항목만 체크

## 2단계: ROADMAP.md 업데이트

`docs/ROADMAP.md`를 읽고 다음 규칙으로 수정하세요:

### 체크박스 규칙
- 구현 완료 확인된 항목: `- [ ]` → `- [x]`
- Task 전체가 완료된 경우: `### Task XXX:` → `### ✅ Task XXX:`
- Task가 부분 완료인 경우: `### - 우선순위 Task XXX:` 유지, 완료된 하위 항목만 `[x]`로 변경
- 미완료 항목: 변경 없음

### 진행률 업데이트
파일 하단 `## 현재 진행 상황` 섹션의 진행률을 실제 완료 비율로 업데이트하세요:
- Phase별 완료된 Task 수 / 전체 Task 수로 계산
- `**다음 작업**` 항목을 다음으로 진행할 미완료 Task로 업데이트

### 최종 업데이트 날짜
파일 상단의 `**최종 업데이트**` 날짜를 오늘 날짜(YYYY-MM-DD)로 변경하세요.

## 3단계: 변경 내역 보고

업데이트 완료 후 다음 형식으로 보고하세요:

```
## ROADMAP.md 업데이트 완료

### 새로 완료 처리된 항목
- ✅ Task XXX: [Task 이름]
- ...

### 진행률 변경
| Phase | 이전 | 현재 |
|-------|------|------|
| Phase N | X% | Y% |

### 다음 작업
Task XXX: [다음으로 진행할 작업 이름]
```

## 주의사항
- ROADMAP.md에 없는 새 항목을 추가하지 마세요
- 이미 `✅`로 표시된 Task는 건드리지 마세요
- 코드 파일을 수정하지 마세요 — ROADMAP.md만 수정합니다
- 확실하지 않은 항목은 미완료 상태로 유지하세요
